# Pokéaventura

Pokédex interactiva construida con React, TypeScript y Vite usando la [PokéAPI](https://pokeapi.co/).

## Cómo ejecutar

```bash
cd my-app
npm install
npm run dev
```

También se puede generar una versión de producción con `npm run build`.

## Qué incluye

- Pueblo pixel art explorable con teclado, flechas y controles táctiles.
- Atlas de nueve regiones con catálogo de especies.
- Búsqueda por nombre, número y algunas formas regionales.
- Ficha detallada con perfil, combate, biología, archivo, estadísticas, movimientos, sprites y sonidos.
- Equipo inicial interactivo y manejo de carga, errores, reintentos y cierre con Escape.
